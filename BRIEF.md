# BRIEF — mercurius-media-video

Небольшой HTTP-сервис вокруг ffmpeg на AMPHP. Для агента он превращает видео в кадры и звуковую дорожку, когда модель
видео не назначена: кадры смотрит модель зрения, звук распознаёт модель речи. Ещё он конвертирует звук. Без модуля
агент работает, но действие `media video` без модели видео отвечает, чего не хватает.

## Назначение и границы

Сервис делает:

- `frames` — длительность, до 32 кадров JPEG равномерно по всему видео (ширина 768 px) и звук моно 16 кГц в M4A;
- `audio` — звук файла в `mp3`, `wav`, `ogg` или `m4a`, моно 16 кГц.

Остаётся в приложении (`src/Infrastructure/Media/VideoService.php`, `src/App/Agent/Tool/Files/MediaTool.php`):

- выбор, звать ли модель видео или модуль; сколько кадров просить (`media video` берёт до 8);
- вызов моделей зрения и речи, учёт расхода в `llm_calls`, лимиты участника;
- чтение файла из песочницы участника и рамка недоверенных данных для результата.

Модуль ничего не хранит: у каждого запроса своя временная папка, она удаляется после ответа.

## Устройство

| Путь / файл | Что делает |
|---|---|
| `GET /health` | `{"status":"ok","module":"media-video"}`, без токена |
| `POST /frames?count=N` | видео в теле; JSON `{"seconds", "frames": [base64 JPEG], "audio": base64 M4A или null}`; `count` по умолчанию 8, от 1 до 32 |
| `POST /audio?format=F` | файл в теле; звук в формате `F` (по умолчанию `mp3`), `application/octet-stream` |
| `bin/media-video` | запуск: читает переменные окружения, поднимает сервер, останавливается по SIGINT и SIGTERM |
| `src/Server.php` | HTTP: токен, предел тела, коды ответов |
| `src/Ffmpeg.php` | запуск ffprobe и ffmpeg, временная папка, кадры и звук |
| `src/Transcoder.php`, `src/VideoParts.php` | интерфейс преобразования и результат `frames` |

Ответы с ошибкой: `401` — нет или неверен токен, `400` — пустое тело, `413` — тело больше предела, `422` — ffmpeg не
прочитал файл (текст причины до 300 символов), `500` — без подробностей.

## Безопасность и пределы

- Вход — `Authorization: Bearer <MEDIA_VIDEO_TOKEN>`, сравнение `hash_equals`; токен короче 16 символов — сервис не
  стартует (код 78).
- Тело больше предела отклоняется до чтения целиком: `MEDIA_VIDEO_MAX_MB`, по умолчанию 25, допустимо 1–500.
- ffmpeg и ffprobe запускаются списком аргументов, без оболочки, с `-threads 2` и `-protocol_whitelist file`:
  плейлист внутри файла не уведёт ffmpeg в сеть.
- Каждый запуск ffmpeg ограничен `MEDIA_VIDEO_TIMEOUT` (по умолчанию 120 с, допустимо 10–1800); по истечении процесс
  убивается.
- Временная папка запроса создаётся с правами `0700`.
- Сервер принимает до 64 соединений; `memory_limit` PHP — 512 МБ.
- Образ: пользователь `media` (uid 10040). Compose: сеть `internal`, `read_only`, `tmpfs /tmp` 256 МБ,
  `mem_limit: 1g`, `pids_limit: 128`, `no-new-privileges`. Порт наружу не публикуется.

## Решения

- ffmpeg вынесен из песочницы в отдельный модуль: минимальные требования ядра не растут из-за тяжёлых зависимостей.
- Два потока ffmpeg: на многоядерном хосте ffmpeg открывает десятки потоков, а у контейнера предел процессов.
- Видео без звука — не ошибка: `audio` в ответе `null`.
- Длительность, которую ffprobe не определил, считается за 1 с: кадры всё равно извлекаются.
- Логи без имён файлов и содержимого: в журнал идёт только класс ошибки.

## Проверки

- `composer check` — PHPUnit (`test/FfmpegTest.php`, `test/ServerTest.php`), PHPStan и Psalm. Тесты ffmpeg
  пропускаются там, где ffmpeg не установлен.
- CI (`.github/workflows/ci.yml`): одна задача, PHP 8.2, `composer install` и `composer check`; изменения только в
  `*.md` CI не запускают.

## Связь с Меркурием

- Профиль compose — `media-video`: добавить в `COMPOSE_PROFILES`.
- `.env`: `MEDIA_VIDEO_TOKEN` (пусто — модуля нет), `MEDIA_VIDEO_URL` (по умолчанию `http://media-video:8091`).
- `ServiceModules` спрашивает `/health` при старте и раз в минуту; без ответа часть `media video` без модели видео
  недоступна.
